# Material Neon Icons

A local file icon theme based on Material Icon Theme 5.38.1 by Philipp Kief / Material Extensions. All original file icons and associations are retained except Markdown and CSV, which use new SVGs. Eleven project folder names have distinct colors and symbols.

The original Material Icon Theme is licensed under MIT; its license is included in this package.

To activate, open **Preferences: File Icon Theme** in VS Code and choose **Material Neon Icons**. This does not change the color theme.
